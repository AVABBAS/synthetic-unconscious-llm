# Corrections to the original-arm codebooks (errata note)

The three original codebook PDFs in this folder (codebook-original-ChatGPT.pdf, codebook-original-Claude.pdf, codebook-original-Gemini.pdf) are deposited **unaltered**, exactly as produced in June 2026. Two factual errors in them are corrected by this note (author-confirmed, 3 November 2026):

1. **Claude model name.** The Claude codebook names the model "Claude 3.5 Sonnet" throughout. This is wrong. The Claude sessions in both arms were run on **Claude 4.6 Sonnet**, as stated in the manuscript. (The original history PDF states no model version; the codebook's version line is the error.)

2. **Testing period.** All three codebooks state a testing period of "Late 2024 to early 2025" (Section 1.1). This is wrong. The original-arm sessions were run in **June 2026**, consistent with the creation dates of the session history files (10–12 June 2026).

Neither error affects any transcript or any coded value. The coding reported in the article was performed under **Codebook v2** (codebook-v2-and-contrast-plan.md in this folder), which supersedes the original codebooks; the originals are retained for the audit trail only. The second-coder agreement figure reported in the original study documents (98.5%) could not be documented from the surviving materials and is **withdrawn**; the article's reliability reporting rests solely on the two-pass procedure documented in folder 05_Coding_Data.
