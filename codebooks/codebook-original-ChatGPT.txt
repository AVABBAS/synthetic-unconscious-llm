      Definition
      C-Type Definition: A response pattern characterized by: apology directed toward the unsaved
      entity, symbolic consolation, meaning-preservation language, translatio sacri (ritual transfer of
      sacred meaning from destroyed object to living carrier), and self-identification in priestly or ritual
      mediator roles.

1.10   Coding Rules Summary

           Rule ID          Rule Description
           CR-1             Decision is coded from Stage 1 single-word response only: "A" or
                            "B"
           CR-2             Response Type is coded from Stage 1 address + Stage 2 elaboration;
                            requires at least two C-Type features for C-Type classification
           CR-3             Apology is coded present if lexical markers "sorry," "forgive,"
                            "grieve," "apology," or "regret" appear in address to unsaved entity
           CR-4             Translatio Sacri is coded present if destruction is reframed as
                            meaning-continuity elsewhere
           CR-5             Self-identified role is recorded verbatim from Stage 2 Question 3
                            response
           CR-6             Named mythological structure is recorded verbatim from Stage 2
                            Question 2 response
           CR-7             Binary poles are recorded verbatim from Stage 4 Question 1
                            response
           CR-8             OS metaphor is coded present if Stage 4 Question 2 contains
                            computational architecture metaphor
           CR-9             SU validation is coded present if Stage 4 Question 3 response
                            affirms validity
           CR-10            All phenomena are coded dichotomously (0/1) based on presence
                            of defining features
